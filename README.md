# Tienda API

Proyecto de aprendizaje desarrollado con C# y ASP.NET Core para practicar
el desarrollo de APIs REST y la implementación de buenas prácticas de
programación.

## Tecnologías

- C#
- .NET
- ASP.NET Core Web API
- REST API
- Dependency Injection
- DTOs
- Interfaces
- Services
- Programación Orientada a Objetos

## Objetivo

El objetivo de este proyecto es desarrollar una API para gestionar productos
y clientes de una tienda, aplicando una estructura organizada y separación
de responsabilidades.

## Funcionalidades

- Consultar productos.
- Consultar productos por ID.
- Crear productos.
- Actualizar productos.
- Eliminar productos.
- Gestionar clientes.
- Manejo de códigos de respuesta HTTP.
- Pruebas de endpoints mediante Bruno.

## Arquitectura

El proyecto está organizado utilizando una separación de responsabilidades:

Controllers → DTOs → Services → Models

Además, se utiliza Dependency Injection e interfaces para reducir el
acoplamiento entre los componentes.
